01 / 选择系统

Windows：新手先用图形版

VoiceStudio v0.5.7-beta.2 / audio.cpp · 按版本文档整理，尚未实测

通过应用安装 Breeze 模型与运行时，无需手动配置 Python 环境。也可选择便携版教程。

版本说明：v0.5.7-beta.2 为预发行版

截至 2026.10.26，0.5.7 系列的公开桌面包是 v0.5.7-beta.2 预发行版。本文固定到这个版本；GitHub 的 releases/latest 当前仍指向 v0.5.6。本文不再推荐 v0.5.6，也不将 Beta 写成稳定版。

01下载 Windows x64 安装包

适用于 Windows 10 / 11 的 Intel 或 AMD x64 电脑。预留约 10 GB 空间，下载 VoiceStudio v0.5.7-beta.2 · Windows x64 EXE，并按同一发布页的 SHA256SUMS.txt 校验。这里下载的是应用安装包；便携 ZIP 另见便携版教程；Windows ARM 机型不在本教程范围。

02完成应用的首次设置

运行安装程序，选好安装位置；首次启动按应用提示安装本地运行环境（Install local runtime）。应用会准备所需依赖，不需要另外照搬本文 PyTorch Skill 的环境。希望放到其他盘，可在首次设置的 App environment 旁选择 Change…，确认界面列出的环境、数据与模型目录。

03安装 Breeze 模型与 audio.cpp

进入 Settings → Models，安装 Breeze-TTS-2 对应权重，在 audio.cpp 引擎行点 Install runtime。再到 Model Catalogue 的 TTS 页，确认 Breeze-TTS-2 Q8_0 已安装，并明确选择 audiocpp / Use；默认引擎不一定是 Breeze。

VoiceStudio 在 Win / Mac 上使用 audio.cpp 专用的 Q8_0 权重，约 4.73 GiB。便携版教程的 3.57 GB GGUF 来自另一套实现，不能按文件名直接替换。AMD 显卡需使用带 Vulkan 支持的 audio.cpp 运行时；PyTorch 引擎的 CUDA 加速不适用于 AMD。

04先生成一句短音频

在音色设计界面选 Breeze-TTS-2 / audiocpp，填一句中文和声音描述后生成，再播放检查。声音设计可从 CFG 4 开始；克隆则提供参考音与准确逐字稿。首次生成会启动引擎，遇到错误先看应用的引擎状态与日志。

之前为什么推荐 Windows 便携版？

因为本文在 Windows 上从下载、解压到生成实际跑通的是便携版，不代表 VoiceStudio 不能在 Windows 用。VoiceStudio 把环境、模型和操作集中在图形界面，更适合想少碰命令的新手；本文目前尚未实测它的 Windows 安装与生成，因此保留下面已验证的 NVIDIA 便携路线供选择。

依据：v0.5.7-beta.2 Windows 安装说明、audio.cpp 引擎说明。安装包和具体后端是否适合本机，仍需实际启动和生成确认。

macOS 安装

VoiceStudio v0.5.7-beta.2 / audio.cpp · 按版本文档整理，尚未实测

适用 Apple Silicon（M 系列芯片）。下方为图形化安装步骤，尚未实测。

01确认 Mac 型号

打开“ → 关于本机”，确认是 Apple Silicon（M 系列芯片），系统为 macOS 13.3 或更新。VoiceStudio 文档要求约 10 GB 空间用于应用、环境和模型，建议另留余量。Intel Mac 的 VoiceStudio 本地后端目前不受支持。

02下载 0.5.7 系列的 Apple Silicon 安装包

直接下载 VoiceStudio v0.5.7-beta.2 · Mac arm64 DMG，按同一版本发布页的 SHA256SUMS.txt 校验。文件名应为 VoiceStudio-Electron-0.5.7-beta.2-mac-arm64.dmg；不要使用仍会跳到 v0.5.6 的 releases/latest 链接。

退出旧版 VoiceStudio，保留声音、项目与参考录音备份；打开 DMG，把应用拖进“应用程序”替换旧版，再启动并按提示准备本地环境。若更新提示只提供 0.5.6，按本段链接手动安装 0.5.7 Beta。发布说明列出了 Mac 签名、公证与启动相关修复；本文尚未实测，不保证解决每一种旧版故障。

03在应用里安装引擎与模型

进入 Settings → Models，找到 Breeze-TTS-2 的 audio.cpp 模型，按界面安装；在 audio.cpp 引擎行点击 Install runtime。在 Model Catalogue 中明确选择 audiocpp，并在 Weights 中确认 Breeze-TTS-2 Q8_0 已安装。

此引擎的 Q8_0 约 4.73 GiB。不要放入 Windows 那份 3.57 GB GGUF；同为 Q8_0，不代表文件兼容。

04从短句开始生成

选择 Breeze-TTS-2 / audiocpp，用音色设计模式输入一句中文和声音描述，再生成试听。引擎会在第一次生成时启动。Mac 这条路线尚未在本机验证，按钮名称与排错请对照v0.5.7-beta.2 引擎文档。

只想先体验声音，可以直接使用开头的官方网页服务，不必等待本地安装。

遇到问题

我是 Intel Mac，可以照着装吗？

这条 VoiceStudio 路线的本地后端不支持 Intel Mac。可以使用官方网页服务，或按项目文档连接另一台电脑上的后端。

能复用 Windows 下载的模型吗？

Win / Mac 的 VoiceStudio 使用同一套 audio.cpp 专用模型。本文另一条 Windows 便携路线使用的 3.57 GB GGUF 格式不同，不能直接搬入 VoiceStudio。优先通过应用的 Model Catalogue 安装对应权重。

安装或启动没有成功？

先确认已安装 v0.5.7-beta.2 的 arm64 包，核对系统版本和可用磁盘空间，再查看macOS 安装说明与应用给出的错误文档。本文尚未在 Mac 上验证排错结果。
