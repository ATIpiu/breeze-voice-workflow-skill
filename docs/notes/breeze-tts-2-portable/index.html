NVIDIA 显卡安装

Windows 11 / NVIDIA RTX 5090 D 实测 · 2026.10.25

这个便携版运行时不需要 Python、Conda 或 CUDA 工具包。我们已从空目录完成重新下载、解压、启动和生成；电脑已有显卡驱动。

01准备系统和显卡驱动

需要 Windows 10/11 64 位（Intel/AMD x64）、支持 AVX2 的 CPU，以及约 6 GB 空闲磁盘空间。新电脑先装好显卡驱动，再继续下面的步骤。

在“设备管理器 → 显示适配器”确认 NVIDIA 显卡型号，到 NVIDIA 官方驱动下载页选择匹配的驱动。按安装程序提示完成，要求重启时先重启。

本 Windows 发布包依赖驱动提供的 Vulkan 运行库（vulkan-1.dll）。免装 AI 环境不等于免装驱动；缺少这个文件时，单加 --cpu 也解决不了。无需安装整套 Vulkan SDK 或 CUDA 工具包。

02下载程序与模型

  • Windows 便携程序 v0.1.3，约 74 MB。
  • 魔搭 Q8_0 模型直链，约 3.57 GB。也可以到魔搭模型文件页找 breeze-tts-2-q8_0.gguf。

本次使用 tardigrade4ai 提供的社区镜像，完整下载后与官方 Q8_0 的 SHA-256 一致，未另建重复镜像。不需要安装魔搭 SDK，也不要下载整仓库的所有量化版本。

03解压，把模型放在程序旁

解压程序，打开含有 breeze-server.exe 的那层文件夹，把 breeze-tts-2-q8_0.gguf 放进去。保留压缩包里的其他文件。

文件位置示例
D:\BreezeTTS\
  breeze-server.exe
  libbreeze.dll
  breeze-tts-2-q8_0.gguf
  start-breeze.cmd
  …压缩包内的其他文件

这个 GGUF 包无需另外下载 audio_tokenizer/。

04启动，生成第一段声音

下载启动文件 start-breeze.cmd，放进同一文件夹，双击。它会先校验模型，再加载和预热，准备好后自动打开浏览器。使用期间保持启动窗口打开。

如果浏览器没有自动打开，稍等后手动访问 http://127.0.0.1:8088/。首次启动需要预热，暂时打不开不代表安装失败。

不下载启动文件，自己启动

在程序文件夹中打开终端，输入：

PowerShell
.\breeze-server.exe breeze-tts-2-q8_0.gguf --host 127.0.0.1 --port 8088 --webui

AMD 显卡安装

未实测依据 v0.1.3 发布说明与构建文档整理。本文没有在 AMD 显卡上验证兼容性、生成效果或速度。

沿用 Windows 便携包和 Q8_0 模型，通过 Vulkan 运行。当前没有单独的 AMD 下载包，这条路线也不需要安装 CUDA 或 ROCm。

01安装 AMD 显卡驱动

在“设备管理器 → 显示适配器”确认 AMD 显卡型号，到 AMD 官方驱动安装说明选择适用驱动，安装后按提示重启。项目要求驱动提供 Vulkan 1.2；旧显卡、核显和笔记本的实际支持情况取决于型号与驱动。

02下载并放好文件

下载 Windows x64 Vulkan 程序包与魔搭 Q8_0 模型。解压程序，把模型放到 breeze-server.exe 旁边，保留其余文件。CPU 也要支持 AVX2。

03打开本地网页

在程序文件夹里右键“在终端中打开”，使用 PowerShell 执行下面的命令。不要添加 --cpu，保留窗口运行。

PowerShell · AMD / Vulkan · 未实测
.\breeze-server.exe breeze-tts-2-q8_0.gguf --host 127.0.0.1 --port 8088 --webui

等待加载和预热，然后打开 http://127.0.0.1:8088/。8088 和相邻的 8089 端口都需要空闲。

04确认显卡参与，再生成短句

查看启动日志的设备信息，确认识别到 AMD 设备并使用 Vulkan 后端，例如 backend: Vulkan0。若只显示 CPU，则不能当作 AMD 显卡加速成功。然后继续下方的网页生成步骤，先用默认参数生成一句短中文。

显存不足可另行尝试 Q4_K；本文同样未验证其运行效果。不应把 NVIDIA 实测速度套用到 AMD 设备。依据：v0.1.3 发布说明、后端与驱动要求。

CPU 安装与运行

未实测以下两种方法均依据项目文档整理，没有在本机验证纯 CPU 生成、编译结果或耗时。

当前 v0.1.3 没有独立的 Windows CPU 预编译包。可以先用便携包的 CPU 模式；电脑没有 Vulkan 运行库时，再选择纯 CPU 编译。

方法 A：已有 Vulkan 运行库，使用 --cpu

  1. 下载 Windows x64 程序包与魔搭 Q8_0 模型；解压程序，把模型放到 breeze-server.exe 旁边，保留其他文件。
  2. 确认 CPU 支持 AVX2，系统已有 vulkan-1.dll。该发布包即使只用 CPU，仍有这个加载依赖。
  3. 先关掉其他 Breeze 启动窗口，在程序文件夹打开 PowerShell，执行：
PowerShell · CPU 模式 · 未实测
.\breeze-server.exe breeze-tts-2-q8_0.gguf --cpu --host 127.0.0.1 --port 8088 --webui

等待启动，确认日志使用 CPU 后端，再打开 http://127.0.0.1:8088/。用 VOICE DESIGN、CFG 1 和一句短文本开始，首次关闭流式生成。CPU 的实际速度取决于处理器和内存，本文没有耗时数据。

缺少 vulkan-1.dll 时，--cpu 无法消除现成程序的 DLL 依赖。请用下面的纯 CPU 编译方法。

方法 B：不依赖 Vulkan，自己编译纯 CPU 程序

这是进阶路线，也未实测。无需安装 Python、CUDA 或 Vulkan SDK，但需要 Git、CMake、Ninja 和支持 C++17 的编译器。

  1. 安装 Git for Windows 和 Microsoft C++ Build Tools。在安装器中选择“使用 C++ 的桌面开发”，确认包含 x64 MSVC 工具、Windows SDK 和“用于 Windows 的 C++ CMake 工具”（含 Ninja）。
  2. 从开始菜单打开 x64 的 Developer PowerShell / 开发者 PowerShell，让编译器工具可用。切换到一个新建的工作目录，依次执行下面的命令；每一步成功后再继续。
开发者 PowerShell · 纯 CPU 编译 · 未实测
git clone --branch v0.1.3 --recursive https://github.com/HoppouAI/Breeze-TTS-2.cpp.git
cd Breeze-TTS-2.cpp
cmake -S . -B build-cpu -G Ninja -DCMAKE_BUILD_TYPE=Release -DBREEZE_VULKAN=OFF -DBREEZE_CUDA=OFF -DBUILD_SHARED_LIBS=OFF -DBREEZE_BUILD_SHARED=OFF
cmake --build build-cpu --target breeze-server --parallel

从前面的魔搭链接下载 Q8_0 模型，把它放到仓库根目录（与 build-cpu 文件夹同级）。仍在仓库根目录执行：

启动自己编译的 CPU 程序 · 未实测
.\build-cpu\breeze-server.exe .\breeze-tts-2-q8_0.gguf --cpu --host 127.0.0.1 --port 8088 --webui

启动成功后打开同一个本地网页，继续网页生成步骤。CPU 需要支持构建所用指令集；不要把本机编译的程序直接当作所有旧电脑通用的便携包。

编译命令报错时先检查什么？

找不到 cl、cmake 或 ninja：确认安装了对应组件，并使用 x64 开发者终端。提示缺少 third_party/ggml：在仓库目录执行 git submodule update --init --recursive。其他编译或运行错误请保留完整日志，对照项目构建文档；本文尚未验证排错结果。

依据：v0.1.3 CPU 构建与后端选择、服务启动参数、微软 CMake 工具安装说明。

  2. TEXT TO SPEAK 填要读的文字；VOICE DESCRIPTION 填声音描述。

本机实测

Windows 11、RTX 5090 D 上，全新下载的程序和模型在仅保留 Windows 系统工具的环境下，通过 Vulkan 显卡生成了这段 6.08 秒、24 kHz 单声道 WAV。CFG 为 1，Seed 为 1234；自动转写与上面的文字一致，波形无削波。未进行人工听感评测。

6.08 秒是音频时长，不是生成耗时。

模型Q8_0

首次可关闭流式生成。声音描述用：成年男性，标准普通话，语速适中，吐字清楚。

  • 给预热一点时间。等浏览器自动打开，别因为几秒没反应就连点多个启动窗口。
  • 从短句开始。同一段文字，Seed 42 生成了 5.60 秒，Seed 1234 生成了 6.08 秒；种子会影响结果，先固定种子比较。
  • 生成后对照原文试听。一次自动转写把“博客”写成“播客”；仅凭转写不能判断是识别差异还是发音差异。DONE 代表生成结束，还需要检查成品。
  • 保留一个启动窗口。关窗口会停止服务，下次双击重新启动。端口占用先关旧窗口；模型不完整或校验失败时，重新检查下载。

量化版本怎么选

第一次先选 Q8_0。显存紧张再考虑 Q4_K；F16 文件更大，本文未做音质对比。

模型下载大小本文验证
Q4_K · 量化约 2.54 GB未运行
Q8_0 · 量化约 3.57 GB网页生成通过
F16 · 非量化浮点约 6.28 GB未运行

GB 按十进制计算。显存还包含运行开销；量化不保证更快。初次使用先避开文件名带 -dd 的实验版本。

遇到问题

找不到模型？

确认文件下载完整、名称是 breeze-tts-2-q8_0.gguf，且与 breeze-server.exe 在同一层。启动文件也要在这一层，不能留在“下载”文件夹里。

缺少 vulkan-1.dll？

预编译包需要显卡驱动提供这个运行库，添加 --cpu 也不能消除它的 DLL 加载依赖。可更新厂商驱动，或按 CPU 路线编译关闭 Vulkan 的纯 CPU 程序。

网页打不开？

先等校验、加载和预热完成。若旧程序占用了端口，先关旧窗口；也可在手动命令中把 8088 改为 8098，再访问 http://127.0.0.1:8098/。还需确保相邻的 8099 端口空闲。

生成很慢？

检查启动窗口是否显示 Vulkan 显卡，是否回退到了 CPU，并检查显卡驱动。本文没有实测 CPU 或其他显卡的速度。
